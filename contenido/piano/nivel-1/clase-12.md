### 📖 Leer un cifrado
- Cada letra (C, F, G) dice qué acorde tocar **desde ese momento hasta que aparezca otra letra**.
- Las barras ( | ) separan los compases.
- Si un compás tiene dos acordes (por ejemplo, «F C»), cada uno dura 2 tiempos.
- Miro el cifrado **un compás por delante** de lo que estoy tocando.

![Cómo se lee un cifrado](piano/img/P1_leer_cifrado.svg)

Las canciones son melodías tradicionales: mi profesor o un compañero canta o toca la melodía, y yo acompaño. Elijo **dos**.

### 🎵 Canción 1 · «Estrellita» (canción popular francesa)
**Compás:** 4/4 · **Patrón:** 1 o 2

```
| C     | F   C | F   C | G   C |
| C   F | C   G | C   F | C   G |
| C     | F   C | F   C | G   C |
```

### 🎵 Canción 2 · «Cuando los santos marchan» (tradicional)
**Compás:** 4/4 · **Patrón:** 1 o 2

```
| C | C | C | C |
| C | C | G | G |
| C | C | F | F |
| C | G | C | C |
```

### 🎵 Canción 3 · «Sublime gracia» (melodía tradicional)
**Compás:** 3/4 (vals) · **Patrón:** 1, 2 o 3

```
| C | C | F | C |
| C | C | G | G |
| C | C | F | C |
| C | G | C | C |
```

## Preguntas de repaso

1. En un cifrado, ¿hasta cuándo dura un acorde?
   - Solo un tiempo
   - ✔ Hasta que aparece la siguiente letra
   - Siempre un compás entero
   > El acorde vale desde donde se escribe hasta que aparece otro.
2. En 4/4, si un compás dice «F C», ¿cuánto dura cada acorde?
   - 1 tiempo
   - ✔ 2 tiempos
   - 4 tiempos
   > Dos acordes en un compás de 4/4: 2 tiempos cada uno.
3. ¿En qué compás está «Sublime gracia»?
   - 2/4
   - ✔ 3/4
   - 4/4
   > Es un vals: UN-dos-tres. Se puede acompañar con el patrón 3.
